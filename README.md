# Ring Breaker Web

スマホブラウザで遊べる、リング状の敵をビームで削る広告ゲーム風プロトタイプです。

## 遊び方

- 中央の自キャラは動きません
- 長押し・ドラッグでビームの向きを変えます
- リング状の敵を全部壊すとステージクリアです
- レベルアップしたら3択カードから強化を選びます

## 入っている機能

- スマホ縦画面対応
- リング状の敵が時計回りに接近
- セグメントごとのHP管理
- ビーム攻撃
- オーラ攻撃
- チェイン強化
- 衛星オーブ強化
- レベルアップと3択強化
- ステージ制

## GitHub Pagesで公開する方法

1. GitHubのリポジトリページを開く
2. Settings を開く
3. Pages を開く
4. Source を Deploy from a branch にする
5. Branch を main、フォルダを /root にする
6. Save を押す

少し待つと、以下のようなURLで開けます。

https://umimuk.github.io/ring-breaker-web/
